🪨✋✌️ Rock Paper Scissors – Mini Game

A simple, fast, and modern Rock‑Paper‑Scissors game built with HTML, CSS, and JavaScript.
The player competes against the computer with a live score system, emoji buttons,
and a clean dark‑mode UI.

- 🎮 Features
* 🧍 Player vs. 🤖 Computer
* ✊ ✋ ✌️ Emoji‑based selection
* 🔢 Live score tracking
* 🎨 Modern dark theme
* ⚡ Instant win/lose/tie feedback
* 🔁 Randomized computer choice
* 🧼 Clean and readable code structure

- 🛠️ Technologies Used
* HTML5
* CSS3 (Dark mode, hover effects, circular buttons)
* JavaScript (ES6)

- 🚀 Live Demo
👉 https://verwegverweg.github.io/rock-paper-scissors/

- ▶️ How to Play
* Click one of the three buttons: Rock, Paper, or Scissors
* The computer makes a random choice
* The result is displayed instantly
* Scores update automatically
